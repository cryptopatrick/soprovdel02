# SO-prov: Andra världskriget, del 2

Provet: https://cryptopatrick.github.io/soprovdel02/

**Del 2** täcker kriget 1941–1945 och Förintelsen:
- Kriget blir globalt (Operation Barbarossa, Pearl Harbor, allierade)
- Vändpunkter (Stalingrad, el-Alamein, D-dagen)
- Deutschlands nederlag och atombomberna
- Förintelsen och nazisternas förbrytelser

18 frågor, 110 poäng, 60 minuter. Claude rättar med förklaringar.

- `pluggguide.md` – pluggguiden (samma format som del 1).
- `fragor.js` – frågor och facit.
- `index.html` – provsidan (GitHub Pages).
- `server/` – rättningsserver på VPS (soprov2.49-12-204-84.sslip.io, port 8793).

Uppdatera servern: `server/drift/deploy.sh`
